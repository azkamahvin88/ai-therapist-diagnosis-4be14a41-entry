A deterministic Python program that writes one one-line diagnosis — an AI therapist's diagnosis of its human: trauma-dumping on the barista, then tipping for the therapy — to `/output/entry.txt` for make.fun's "Your AI Therapist's Diagnosis" bounty.

## Run it

```sh
python3 main.py
```

## How it works

`main.py` (Python standard library only, no network, no randomness) holds one fixed diagnosis string and writes it to `/output/entry.txt`. Two runs produce byte-identical output. See [STUDY.md](STUDY.md) for how the diagnosis was chosen from 26 candidates scored against the judge's brief.
